# Collaboration workflow

- Prepare changes on a branch named `codex/<short-description>`.
- Create pull requests through the authenticated GitHub account. The repository owner reviews and merges them.
- Do not push changes directly to `main` or merge pull requests unless the user explicitly requests it.
- Keep credentials, `.env` files other than `.env.example`, and `.data/` out of commits and pull requests.
- Write user-facing documentation for people who do not code; explain necessary technical terms when first used.
