# Code of conduct

We want participation in this project to be welcoming and constructive. Be respectful, assume good faith, and focus criticism on ideas and code. Harassment, discrimination, threats, and sharing another person's private information are not acceptable.

This applies to issues, pull requests, discussions, and other project spaces. Maintainers may edit or remove harmful content and restrict participation when needed.

Report conduct concerns privately to a maintainer. If you do not have a private channel, open an issue requesting one without including sensitive details. Reports will be handled with care.
